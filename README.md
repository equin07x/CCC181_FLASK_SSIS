Readme file for CCC181 Flask Backend Framework 🚀

To run, first create the .venv python environment by using the command ⚡

    > python -m venv .venv
    > source .venv/bin/activate

------------------------------------


After those commands, you have to specify your .env variables for it to connect to the database 🥭


------------------------------------

Now run the command 🔥

    > python main.py
